## Bug

The `apart()` function returns the wrong result when the expression contains a
symbolic parameter.

```python
from sympy import symbols
a = symbols('a', real=True)
t = symbols('t', real=True, negative=False)
bug = a * (-t + (-t + 1) * (2 * t - 1)) / (2 * t - 1)

bug.apart(t)          # returns -a*t  (WRONG)
bug.subs(a, 1).apart(t)  # returns -t + 1/2 - 1/(2*(2*t - 1))  (correct)
```

The result is wrong when the expression has a symbolic coefficient. Substituting
a concrete value first gives the correct result.
